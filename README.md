# REELTIME — คู่มือใช้งาน

เว็บแคตตาล็อกหนังที่สร้างด้วย React, Node.js และ PostgreSQL มีหน้าเว็บสำหรับค้นหา/รับชม และหน้าแอดมินสำหรับจัดการรายการหนัง

## โครงสร้างโฟลเดอร์

```text
web-movie/
├── README.md
├── Back-end/
│   ├── .env.example
│   ├── db.js
│   ├── package.json
│   ├── server.js
│   ├── server/
│   │   └── models/
│   └── uploads/              # ไฟล์หนังและรูปปกที่อัปโหลด
└── Front-end/
   └── client/
      ├── index.html
      ├── package.json
      ├── public/
      └── src/
         ├── App.tsx
         ├── App.css
         ├── index.css
         ├── interface.ts
         ├── main.tsx
         ├── assets/
         └── components/
            ├── Chat.tsx
            ├── JoinRoom.tsx
            ├── Login.tsx
            └── Message.tsx
```

ไฟล์ `.env` ใช้เก็บค่าลับเฉพาะเครื่อง จึงไม่แสดงในแผนผังและไม่ควร commit ขึ้น Git ส่วน `node_modules/` และ `dist/` จะถูกสร้างขึ้นเมื่อติดตั้งแพ็กเกจหรือ build โปรเจกต์

## สิ่งที่ต้องมี

- Node.js และ npm
- PostgreSQL ที่กำลังทำงานอยู่ (จัดการฐานข้อมูลได้จาก pgAdmin 4)
- ฐานข้อมูลชื่อ `chat_app`

## ตั้งค่าครั้งแรก

1. เปิด PostgreSQL ใน pgAdmin 4 และสร้างฐานข้อมูลชื่อ `chat_app` หากยังไม่มี:
   - คลิกขวา **Databases** → **Create** → **Database...**
   - ตั้งชื่อเป็น `chat_app` แล้วกด **Save**
2. เปิด `Back-end/.env` และตั้งค่าให้ตรงกับ PostgreSQL ในเครื่อง:

   ```env
   PGHOST=localhost
   PGPORT=5432
   PGDATABASE=chat_app
   PGUSER=postgres
   PGPASSWORD=รหัสผ่าน-postgres-ของคุณ
   PORT=3001
   CLIENT_ORIGIN=http://localhost:5173
   JWT_SECRET=ใส่-secret-ที่เดายาก
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=ตั้งรหัสผ่านแอดมินที่เดายาก
   ```

   เก็บไฟล์ `.env` ไว้ในเครื่อง อย่าแชร์หรือ commit ไฟล์นี้ขึ้น Git เพราะมีรหัสผ่านและ secret
3. ติดตั้งแพ็กเกจ (ทำครั้งแรก หรือหลังเปลี่ยน dependency):

   ```powershell
   cd "Back-end"
   npm install
   cd "..\Front-end\client"
   npm install
   ```

   Backend จะสร้างตาราง `movies` ให้อัตโนมัติเมื่อเชื่อมต่อฐานข้อมูลสำเร็จ

## เปิดเว็บสำหรับพัฒนา

เปิด PowerShell สองหน้าต่าง โดยเริ่ม Backend ก่อน

**หน้าต่างที่ 1 — Backend**

```powershell
cd "Back-end"
npm start
```

ข้อความ `Movie server running on port 3001` หมายถึง Backend พร้อมใช้งาน

**หน้าต่างที่ 2 — Frontend**

```powershell
cd "Front-end\client"
npm run dev
```

สามารถเริ่ม Frontend จากโฟลเดอร์โปรเจกต์หลักได้ด้วย `npm run dev` เช่นกัน โดยสคริปต์ที่ `package.json` ระดับ root จะส่งคำสั่งต่อไปยัง `Front-end/client`

เปิด URL ที่ Vite แสดง โดยค่าปกติคือ:

- หน้าเว็บ: <http://localhost:5173>
- หน้าแอดมิน: <http://localhost:5173/admin>
- ทีมพัฒนา: <http://localhost:5173/team>
- รายการหนัง API: <http://localhost:3001/api/movies>

ปล่อยหน้าต่าง terminal ทั้งสองไว้ขณะใช้งาน หากหยุดคำสั่งหรือปิด terminal เซิร์ฟเวอร์จะหยุดทำงาน

## วิธีใช้หน้าเว็บ

- ใช้ช่องค้นหาด้านบนเพื่อค้นหาจากชื่อหนัง หมวดหมู่ หรือปีที่ฉาย
- เลือกหมวดหมู่และปีที่ฉายเพื่อกรองรายการ หรือกด **รายการโปรด** เพื่อดูเรื่องที่บันทึกไว้
- กดรูปปกเพื่อเปิดหน้ารายละเอียด ซึ่งมีเรื่องย่อ ปุ่มเพิ่มรายการโปรด หนังแนะนำ และเครื่องเล่น
- ระบบบันทึกตำแหน่งดูไว้ในเบราว์เซอร์เครื่องนี้และเล่นต่อจากตำแหน่งเดิมได้
- เปิดหน้า **ทีมของเรา** หรือ <http://localhost:5173/team> เพื่อดูโปรไฟล์ตัวอย่างสมาชิกทีมพัฒนา 3 คน
- เปิดหน้ารายละเอียดของหนังได้ที่ `/movie/<รหัสหนัง>` เช่น <http://localhost:5173/movie/2>

## วิธีใช้หน้าแอดมิน

1. เปิด <http://localhost:5173/admin>
2. เข้าสู่ระบบด้วย `ADMIN_USERNAME` และ `ADMIN_PASSWORD` จาก `Back-end/.env` (ค่าเริ่มต้นของชื่อผู้ใช้คือ `admin`)
3. กรอกชื่อหนัง ซึ่งเป็นช่องบังคับ; รายละเอียด หมวดหมู่ และปีที่ฉายเป็นตัวเลือก
4. เพิ่มรูปปกหรือวิดีโอได้ด้วยการเลือกไฟล์ หรือใส่ URL โดยตรง:
   - รูปปก: JPG/JPEG, PNG หรือ WebP
   - วิดีโอ: MP4 หรือ WebM ขนาดไม่เกิน 1 GB ต่อไฟล์
   - ถ้าใส่ทั้งไฟล์และ URL ระบบจะใช้ไฟล์ที่อัปโหลด
5. กด **เพิ่มหนัง** หนังจะแสดงบนหน้าเว็บและในรายการคลังหนังของแอดมิน
6. กด **แก้ไข** ข้างรายการ เพื่อเปลี่ยนชื่อ รายละเอียด หมวดหมู่ ปี รูปปก หรือวิดีโอ แล้วกด **บันทึกการแก้ไข**
   - ถ้าไม่เลือกรูปหรือวิดีโอใหม่ สื่อเดิมจะยังคงอยู่
   - ใช้ **เอารูปปกออก** หรือ **เอาวิดีโอออก** เพื่อลบสื่อนั้นออก
   - หากเลือกรูป/วิดีโอใหม่ ไฟล์ที่ระบบอัปโหลดไว้และไม่ได้ใช้งานแล้วจะถูกลบ
7. กด **ลบ** หากต้องการลบรายการหนังและสื่อที่อัปโหลดของรายการนั้น
8. กด **ออกจากระบบ** เมื่อใช้งานแอดมินเสร็จ
9. ใช้ปุ่ม **ซ่อน/เผยแพร่** เพื่อเอาหนังออกจากหน้าเว็บโดยไม่ลบข้อมูล และใช้ปุ่มลูกศรขึ้น/ลงเพื่อจัดลำดับหนังบนหน้าแรก

ไฟล์ที่อัปโหลดเก็บไว้ใน `Back-end/uploads/` ซึ่ง Git ไม่ติดตาม อย่าลบไฟล์ในโฟลเดอร์นี้เองหากยังต้องการให้หนังที่บันทึกไว้ใช้งานได้

> ช่อง URL วิดีโอรับลิงก์ไฟล์วิดีโอโดยตรงที่เปิดให้เข้าถึงได้ (เช่น `.mp4` หรือ `.webm`) ไม่ใช่ลิงก์หน้า YouTube และการเล่นขึ้นอยู่กับ codec ที่เบราว์เซอร์รองรับ

## สร้าง Frontend สำหรับ production

```powershell
cd "Front-end\client"
npm run build
```

ไฟล์ผลลัพธ์จะอยู่ใน `Front-end/client/dist/`

## แก้ปัญหาเบื้องต้น

- **เชื่อมต่อ PostgreSQL ไม่ได้**: ตรวจสอบว่า PostgreSQL service ทำงานอยู่ และค่า `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD` ใน `Back-end/.env` ถูกต้อง
- **ไม่พบฐานข้อมูล `chat_app`**: สร้างฐานข้อมูลชื่อ `chat_app` ใน pgAdmin 4 แล้วเริ่ม Backend ใหม่
- **เข้าสู่ระบบแอดมินไม่ได้**: ตรวจ `ADMIN_USERNAME` และ `ADMIN_PASSWORD` ใน `Back-end/.env` แล้วรีสตาร์ต Backend หลังแก้ไฟล์
- **อัปโหลดไม่ได้**: ตรวจชนิดไฟล์และขนาดวิดีโอ (ไม่เกิน 1 GB) รวมถึงพื้นที่ว่างบนดิสก์
- **หน้าเว็บติดต่อ API ไม่ได้**: ตรวจว่า Backend ทำงานที่พอร์ต 3001 และ Frontend เปิดที่พอร์ต 5173; แก้ `CLIENT_ORIGIN` หากเปลี่ยนพอร์ต
- **วิดีโอเล่นไม่ได้**: ตรวจว่า URL เป็นลิงก์ไฟล์โดยตรงและเบราว์เซอร์รองรับ codec ของไฟล์
